Install, check, fix.

Everything you need to install Zoomify, understand what your phone supports, verify that your copy is genuine, and solve common problems.

Install Zoomify

  1. On your Android phone, open zoomify.houseli.site and tap Download Zoomify.apk. The file comes from Zoomify's official GitHub Releases page.
  2. Open the downloaded file. If Android asks, allow your browser (or file manager) to install unknown apps.
  3. Open Zoomify and allow Camera access. Microphone access is only needed for recording video with sound.

To update, download the new version and install it over the existing app. You don't need to uninstall first.

Compatibility

Zoomify needs Android 11 or newer. Many features depend on what your phone's camera makes available to apps (not just on its hardware). Zoomify checks this at runtime and only offers what your phone supports.

How v1.1 was tested. It was installed and used on a Samsung Galaxy A36 (real device). The installation and the signing-key update were also tested automatically on Android 11, 12 and 13 emulators. Emulators have no real camera, so those runs check installation and updates, not camera features. Other phones haven't been individually tested.

The v1.1 security update

The private key used to sign Zoomify 1.0 was accidentally made public. In theory, anyone holding that key could have published a fake "update" that Android would accept. Zoomify 1.1 fixes this:

  • It is signed with a new private key that is never published.
  • It carries an Android key-rotation proof (APK Signature Scheme v3). Installing 1.1 over 1.0 works like any normal update.
  • After you install 1.1, your phone rejects any APK signed only with the old key, so a fake can't replace your app.

If you still use 1.0, please update now, and only download Zoomify from this site or its GitHub page.

Verify your download

Genuine Zoomify 1.1+ APKs are signed with this certificate:

SHA-256: 72:96:CD:BF:1D:D6:13:C7:53:17:E4:5A:28:8F:AB:9B:C0:43:D8:2D:E5:33:9D:44:FB:EC:70:BF:91:A7:CC:CF

On a computer with the Android SDK, run apksigner verify --print-certs Zoomify.apk and compare the certificate SHA-256 digest. Each GitHub Release also lists the APK's SHA-256 checksum.

Troubleshooting

"App not installed" or "package conflicts with an existing package"

A copy of Zoomify signed with a different key is already installed, e.g. one from another website. Genuine updates from this site install over genuine copies. If you installed Zoomify from somewhere else, uninstall it, then install from this site. Uninstalling removes the app; photos you saved stay in your gallery.

Google Play Protect warns about the app

Apps installed from outside Google Play can show a warning when the developer is unknown to Play Protect. Check that you downloaded from this site and that the certificate matches the one above before choosing to install.

"Install blocked" or nothing happens when I open the APK

Allow your browser or file manager to install unknown apps: Settings → Apps → (your browser) → Install unknown apps. Then open the file again.

The viewfinder is black

Another app may be using the camera. Close other camera apps, then reopen Zoomify. Also check Settings → Apps → Zoomify → Permissions → Camera.

60 fps, HDR, RAW, 0.5× or telephoto is greyed out or missing

Your phone doesn't make that feature available to apps in the current mode or resolution. For 60 fps, try 1080p, the Sensor HQ path, or turning Horizon lock off. Settings shows the reason under each option.

Where are my photos and videos?

In your phone's storage under DCIM/Zoomify, and in your gallery app's "Zoomify" album. RAW files are saved as .dng next to the JPEG.

Zoomed photos look soft at 20–50×

Beyond your phone's optical zoom, Zoomify crops and enlarges the image. That can't add real detail, so very high zoom always looks softer.
